06
JevBench public-task scorecard
Score predictions from a typed-decision model against JevBench's pinned original, easy and hard public tasks.

      
This is a separate evaluation for models that can answer per-item Noul, Choice and Score rubrics. The fixed-label model above cannot produce these answers. The app checks 231 public tasks, keeps missing or malformed answers in the denominator, and never calls a provider. It cannot calculate JevBench's current official score, which also uses sealed tasks, speed and cost.

      
Run your typed model on the pinned public task files, then upload one JSONL object per task with task_id and probabilities (a map from exact label IDs to probabilities). Official JevBench runner results JSONL with probs_as_returned is also accepted. Optional latency_ms is self-reported.
